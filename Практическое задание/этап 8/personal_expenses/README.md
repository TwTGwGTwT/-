# Учёт личных трат

Веб-приложение для учёта личных расходов: регистрация, траты по категориям,
фильтрация по датам, статистика с графиками и экспорт в CSV.

## Стек
- Go (net/http, html/template), без веб-фреймворков
- SQLite через database/sql (modernc.org/sqlite)
- Chart.js для графиков (подключается через CDN)

## Запуск
1. Установите Go (см. go.mod).
2. Скопируйте `.env.example` в `.env` и при необходимости поменяйте значения:
   - PORT — порт сервера (по умолчанию 8080);
   - DB_PATH — путь к файлу базы SQLite (по умолчанию expenses.db);
   - SECRET_KEY — секретный ключ.
3. Запустите сервер:
   go run ./cmd/main.go
4. Откройте http://localhost:8080 в браузере.

База данных и миграции создаются автоматически при первом запуске
(файлы в папке migrations накатываются при старте).

## Функционал
- Регистрация и вход (пароли хранятся в виде bcrypt-хэша, сессии — в cookie)
- Добавление, редактирование и удаление трат с категориями
- Фильтрация списка по категории и диапазону дат
- Статистика по категориям и месяцам с графиками
- Экспорт трат текущего пользователя в CSV (с учётом фильтров)
